## Descrição do Projeto

O **LabReserva** é um sistema web desenvolvido com o objetivo de facilitar o gerenciamento e a reserva de laboratórios em instituições de ensino.

A plataforma permite que professores consultem os laboratórios disponíveis, visualizem suas capacidades, realizem solicitações de reserva e acompanhem os registros realizados.

O projeto foi desenvolvido como atividade acadêmica da disciplina de **Maturidade em Desenvolvimento de Software**, utilizando HTML, CSS e JavaScript.

O sistema possui uma interface intuitiva, moderna e responsiva, buscando proporcionar uma experiência simples e organizada aos usuários.

## Funcionalidades

O sistema apresenta as seguintes funcionalidades:

- [x] **Dashboard:** apresentação geral do sistema e indicadores de disponibilidade dos laboratórios.
- [x] **Consulta de laboratórios:** visualização dos laboratórios cadastrados, suas capacidades e situações.
- [x] **Filtros de disponibilidade:** identificação de laboratórios disponíveis e indisponíveis.
- [x] **Nova reserva:** formulário para selecionar laboratório, data, horário e finalidade.
- [x] **Validação de campos:** verificação dos campos obrigatórios antes de confirmar uma reserva.
- [x] **Validação de disponibilidade:** bloqueio de reservas para laboratórios indisponíveis.
- [x] **Regra de capacidade:** laboratórios com capacidade inferior a 30 alunos não podem ser reservados para aulas regulares.
- [x] **Confirmação de reserva:** apresentação de uma mensagem de sucesso com os detalhes e protocolo da solicitação.
- [x] **Minhas reservas:** listagem das reservas cadastradas e suas respectivas situações.
- [x] **Armazenamento local:** utilização do LocalStorage para manter os registros no navegador.
- [x] **Responsividade:** adaptação da interface para diferentes tamanhos de tela.

## Acesso ao Projeto

Para executar o projeto localmente, siga as instruções:

1. Faça o download ou clone o repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Localize o arquivo `index.html`.
4. Abra o arquivo diretamente no navegador ou utilize a extensão Live Server.
5. Navegue pelas funcionalidades disponíveis no sistema.

**Observação:** o projeto funciona localmente no navegador, sem necessidade de servidor backend ou banco de dados.
